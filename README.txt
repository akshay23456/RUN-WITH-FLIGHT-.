1. Create a new GitHub repo.
2. Upload ALL files and folders (www/, .github/workflows/build-apk.yml, package.json, capacitor.config.json).
3. Actions tab -> "Build RUN WITH FLIGHT APK" -> Run workflow.
4. After ~5 min open the run -> Artifacts -> RUN WITH FLIGHT-apk -> download, unzip, install app-debug.apk.
